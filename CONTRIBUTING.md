# Contributing to Online Bay Bakery

Thank you for your interest in contributing to **Online Bay Bakery**! We welcome bug reports, feature suggestions, and pull requests.

## How to Contribute

1. **Fork the Repository**
   - Click the "Fork" button at the top right of the repository page.

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/amazing-feature
   ```

3. **Make Your Changes**
   - Adhere to the established code style and naming conventions.
   - Never commit sensitive files (`.env`, private keys, real phone numbers, passwords).
   - Ensure all database queries use prepared statements.

4. **Test Your Changes**
   - Start the local development server:
     ```bash
     php -S localhost:8000
     ```
   - Verify that all pages load cleanly without errors or warnings.

5. **Submit a Pull Request**
   - Push your branch to GitHub and open a Pull Request targeting the `main` branch.
   - Provide a concise summary of what your PR introduces or fixes.

## Code of Conduct

Please maintain a polite, respectful, and collaborative environment.
